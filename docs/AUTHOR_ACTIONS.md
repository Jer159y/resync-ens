# Author actions before public release/submission

The repository and input release are public at the author's request. The supplied reproduction commands do not require the original workspace.

Before journal submission, the authors should:

1. Agree on the licence for original code, manuscript and numerical data. No licence has been invented for the authors. The vendored DynamicsMetrics licence and Copernicus notices are preserved separately.
2. Review the manuscript and references, confirm author roles, funding, conflict-of-interest and any required AI-use statement. Existing manuscript placeholders are preserved as working-draft items.
3. Archive the final code/data version in a DOI-bearing repository and update the manuscript with persistent identifiers. The public GitHub URL and input release are already available.
4. Preserve the input release and its checksums. The original large N-member forecast arrays were not all retained; do not describe this export as a complete raw-output archive. Main numerical experiments can be rerun from the included weights, physical data and code.

No Telegram credential, Google Drive credential, SSH setup or original workspace path is needed by the reproduction commands.
